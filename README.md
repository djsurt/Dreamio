# Dreamio 🌙

A social web app for **capturing dreams**, connecting with friends, and exploring community sentiment.  
Built with the **MERN stack** (MongoDB, Express.js, React.js, Node.js) and deployed on **Heroku**.  

---

##  Features

- **Dream Capture** – Create posts with dream titles, descriptions, tags, and optional images.  
- **Collaboration** – Comment on friends’ dream posts and share interpretations.  
- **Friend Network** – Send/accept friend requests to connect with other dreamers.  
- **Community Feels** – Sentiment analysis across posts to show the overall mood of the community.  
- **Search** – Find dreams by title or tag.  

---

##  Architecture

- **Frontend**: React.js  
- **Backend**: Express.js + Node.js  
- **Database**: MongoDB (Atlas)  
- **Deployment**: Heroku (frontend & backend apps)  
- **CI/CD**: GitHub Actions with automated build/test/deploy pipeline

---

##  Testing

- **Unit Tests**: Implemented with Jest for React components (Posts, Navbar, Auth, etc.).  
- **User Acceptance Tests**: Verified creation, liking, commenting, and sentiment analysis features.  
- **Automated Testing**: Integrated into CI/CD pipeline
